# 疲劳机多源在线损伤度 D(t) 监测看板

工业化风格的实时监测看板，用于回放 6 组主样本的**在线因果流式**损伤评估过程，逐点复现 D(t) 演化、多源信号、分级预警与报警日志。

> 纯前端实现（原生 HTML / CSS / Canvas，零外部依赖、零 CDN），可离线运行。

---

## 2. 页面功能

| 区域                 | 内容                                                                                                  |
| -------------------- | ----------------------------------------------------------------------------------------------------- |
| **顶栏**       | 试件选择（6 组）、台架信息、系统状态灯、时钟                                                          |
| **控制条**     | `开始监测 / 暂停监测`、`复位`、`声音开/关`、回放倍率、试验进程进度条、采样点/AE 事件/数据帧读数 |
| **损伤度仪表** | 实时 D 值、分级色环、三档阈值刻度、峰值 D、寿命进度、剩余裕度                                         |
| **D(t) 趋势**  | D 曲线 + risk 曲线、0.25/0.55/0.85 阈值带、b2/b3 锚、实时游标与跟随读数                               |
| **分级预警**   | 三级指示灯（注意/预警/临危）、各级触发时刻、综合判定文案、证据条（e_ae / e_st / risk）                |
| **多源子面板** | ① AE：事件率柱 + 峰值能量(log) ② FBG：多通道实时曲线 ③ 应变：波形 + 滑动波动 σ ④ 证据层分解      |
| **底栏**       | 报警与事件日志、多源通道健康表                                                                        |

### 操作

| 操作                        | 说明                                                |
| --------------------------- | --------------------------------------------------- |
| `开始监测` / `暂停监测` | 开始或暂停在线回放                                  |
| `复位`                    | 回到试验起点、清空日志                              |
| `回放倍率`                | 30× / 60× / 120×（默认）/ 300× / 600× 实时倍速 |
| 进度条拖动                  | 任意跳转到寿命任意位置（D 为预计算，跳转即时生效）  |
| `声音`                    | 报警提示音开关（分级不同音调，临危为三连方波）      |
| `空格`                    | 播放 / 暂停                                         |
| `←` `→`               | 后退 / 前进 200 帧（100 s）                         |

### 在线语义

看板严格模拟在线监测：**新选择一组数据时看不到任何数据**，各曲线从试验起点随回放生长，
任意时刻只能看到**当前时刻及之前**的信息：

- 主趋势图不预显未来曲线，已回放区带扫描光带与当前值读数标签；
- 多源子面板为滚动窗口，右端锁定当前时刻（前 600 s 从左向右生长，之后窗口滚动）；
- b2 扩展参考 / b3 断裂锚及其图例，仅在回放越过对应时刻后才出现；
- 三级预警灯与各级触发时刻，只在事件真实发生后才点亮 / 显示时间；
- 峰值 D、寿命进度、累计点数等统计量均按"当前时刻及之前"计算；
- 拖动进度条 = 只保留该时刻及之前的信息（等同于在该时刻重新开始观察）。

## 3. 数据生成

看板数据由 `export_dashboard.py` 生成，**严格复用正式方法**：

```bash
cd d:\lixiang
C:\Users\ASUS\.conda\envs\xjtushm\python.exe export_dashboard.py          # 全部 6 组
C:\Users\ASUS\.conda\envs\xjtushm\python.exe export_dashboard.py 016 017  # 指定组
```

流程：`StreamSimulator` 逐点推送 → `OnlineDamageIndex`→
逐点 D / 证据 / 分级 + 各源信号，按 `STEP=5`（10 Hz → 2 Hz）降采样打包。

输出：

```
dashboard/data/
├── index.js       # 组清单与摘要 (window.SHM_INDEX)
└── 016.js ...     # 每组数据包 (window.SHM_DATA[gid])
```

导出的 `t85` 等指标与 README 主表一致（016→95.8%、017→87.0%、018→73.8%、
019→81.3%、020→74.7%、022→96.0%）。

## 4. 数据包字段

```js
window.SHM_DATA["016"] = {
  gid, n, nfr, step, dt, dur,      // 点数 / 帧数 / 降采样步长 / 帧间隔 / 试验时长
  foCols: ["s1",...,"s5"],         // 光纤通道 (022 为空 → 面板显示"未接入")
  meta: { D_end, t25, t55, t85, b2, b3, aeEvents, nFo },
  warn: [ {f, t, lv}, ... ],       // 分级升级事件
  // 波形数组(长度均 = nfr)
  D, risk, eae, est,               // ×1000
  lv,                              // 0/1/2/3
  st,                              // 应变 ×100
  ael,                             // log10(AE峰值)×1000, 无事件 = -99999
  aen,                             // 帧内 AE 事件数
  t,                               // 时间(s)
  fo: { s1:[...], ... }            // 光纤通道 ×100
}
```

## 6. 与正式口径的一致性

- 损伤度由 `shm.damage_index.OnlineDamageIndex` **默认参数**计算（含 latch 加速追赶），
  与 `evaluate.py degree` 口径完全一致；
- 流式入口 `shm.streaming.StreamSimulator`（松散对齐、事件门控 AE 能量），
  与 `evaluate.py` 的 `_stream_d` 一致；
- 阈值 0.25 / 0.55 / 0.85，b2/b3 来自 `weak_labels` 弱标签体系；
- 看板**不重新训练、不引入未来信息**，仅做可视化呈现。
